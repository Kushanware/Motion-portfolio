# Kushkumar Shanware - Interactive Portfolio

A premium, highly interactive software engineering portfolio built with React, TypeScript, and Tailwind CSS. The design focuses on a cinematic "Awwwards-style" aesthetic, featuring dynamic background videos, a subtle film grain overlay, and an interactive command-line terminal widget.

## 🚀 Features

- **Cinematic Background Video:** Optimized video background that anchors the dark, premium aesthetic.
- **Interactive Terminal Widget:** A fully functional, in-browser command-line interface in the About section. Users can type commands like `help`, `about`, `skills`, `projects`, and `resume`.
- **Serverless Contact Form:** Integrated with [Web3Forms](https://web3forms.com/) for seamless email submissions without requiring a backend server.
- **Glassmorphism UI:** Sleek, modern navigation and content cards utilizing backdrop blurs and subtle white borders.
- **Fully Responsive:** Optimized layout spanning mobile to ultra-wide desktop displays.
- **Custom Assets:** Includes a custom SVG favicon and scalable interactive UI elements.

## 🛠️ Tech Stack

- **Framework:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4)
- **Build Tool:** Vite
- **Form Handling:** Web3Forms API
- **Icons & UI:** Custom SVGs and CSS Keyframe Animations

## 💻 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kushkumar-Shanware/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

Start the Vite development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port specified in your terminal) to view it in your browser.

## 📁 Project Structure

- `src/components/` - React functional components (Navbar, HeroSection, ContentSections, TerminalWidget, BackgroundVideo)
- `src/hooks/` - Custom React hooks (e.g., `useTypewriter` for text animations)
- `src/App.tsx` - Main application wrapper and global state for modals
- `src/index.css` - Global CSS, Tailwind imports, and custom keyframes (grain overlay, terminal blink)
- `public/` - Static assets like the background video and favicon
